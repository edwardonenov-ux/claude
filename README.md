# Редизайн airemone.ru — материалы аудита и дизайн-макеты

Автономный аудит сайта AiRemOne (ремонт квартир под ключ, Москва) и подготовка к переезду с InSales на отдельный хостинг с новым дизайном.

## С чего начать утром

1. **`audit/AUDIT.md`** — полный постраничный аудит текущего сайта: что есть, что слабо, что менять по каждому блоку.
2. **`audit/COMPETITORS.md`** — анализ конкурентов рынка ремонта в Москве и где у AiRemOne есть возможность выделиться.
3. **`designs/index.html`** — страница-навигатор: откройте её первой, там превью палитр и ссылки на все варианты и блоки. Каждая папка внутри `designs/` — самостоятельный набор: `hero.html`, `advantages.html`, `footer.html`, `index.html` (собранная демо-страница), `NOTES.md` (палитра/шрифты/описание):
   - `designs/variant-a-warm-editorial/` — тёплый эдиториал, боутик-студия интерьеров, терракота+кремовый, serif-заголовки.
   - `designs/variant-b-dark-premium/` — тёмная премиум-мастерская, единственный тёмный дизайн на рынке, латунь+уголь.
   - `designs/variant-c-bold-kinetic/` — динамичный конструктор, самый смелый, оранжевый+чёрные обводки, отсылки к стройке.
4. **`audit/PROMPT_FOR_DESIGN.md`** — готовый промпт для вставки в Claude/другой AI-инструмент дизайна: выберите один вариант направления (удалите два других прямо в тексте промпта) и вставьте целиком в новый чат — получите основу для полной разработки сайта.
5. **`audit/CLAUDE_CODE_SETUP.md`** — инструкция специально под Claude Code: какие скиллы вызывать (`impeccable`, `animate`, `svg-animations` и др.), как зафиксировать design system файлами (`tokens.css`/`DESIGN.md`) вместо повторения в чате на каждой странице, порядок сборки 10+ страниц, и готовый первый промпт для новой боевой сессии разработки.

## Дальше

Когда выбор направления сделан — переходим к плану разработки: разбивка на страницы/спринты, техстек (рекомендация в `AUDIT.md`, раздел 11), хостинг, перенос контента и фото, интеграция форм с Telegram, SEO-настройка. Это обсуждаем уже вместе.
