### Вариант A — «Тёплый эдиториал»
Референс-настроение: боутик-студия интерьеров, журнальная вёрстка, тактильность, элегантность без холодности.

## В. Структура сайта (сохранить многостраничность, это важно для SEO по гео-запросам в Яндексе)

## Е. Технические требования

- **Стек:** статический сайт (HTML/CSS/JS, можно на генераторе типа Astro/11ty) для максимальной скорости и SEO — сайт небольшой (10–12 страниц), не требует SPA. Если планируется в будущем личный кабинет клиента с онлайн-статусом ремонта — тогда Next.js (React) с SSR. **Решить это до начала разработки** (см. дополнение «Ж»).
- Полная адаптивность (мобильный — приоритет, брейкпоинты минимум 375/768/1024/1440).
- Формы — интеграция с Telegram Bot API для мгновенных уведомлений менеджеру (раз Telegram уже используется для фотоотчётов клиентам).
- Anti-spam защита форм (honeypot/капча), явное согласие на обработку персональных данных (152-ФЗ), сервер/хостинг на территории РФ, если собираются персональные данные.
- Производительность: Lighthouse 90+ на мобильном, оптимизация изображений (WebP/AVIF, lazy loading), анимации на transform/opacity (не layout-свойствах) для 60fps.
- SEO: уникальные title/description по каждой странице и по районам Москвы (гео-запросы), микроразметка schema.org (LocalBusiness, Service, Review, FAQPage), карта сайта, alt-тексты у всех фото.
- Доступность: контраст текста AA минимум, видимый focus-state на интерактивных элементах, анимации уважают `prefers-reduced-motion`.

## Ж. Чего избегать

Фиолетово-синие AI-SaaS-градиенты; шрифт Inter/Roboto/Poppins без выраженной иерархии; карточки «иконка в кружке + заголовок + текст» без индивидуальности; glassmorphism на каждом блоке; всё строго по центру и симметрично; эмодзи вместо иконок; избыточные одинаковые формы на каждой странице (нужна ОДНА умная форма на страницу + мессенджер-кнопки); статичность без единого hover/scroll-эффекта (сайт должен «жить», но не быть перегружен анимацией — 1 заметная анимационная фишка на блок, не больше).

## З. Что важно сохранить из текущего сайта (это работает, не переизобретать)

Конкретные цифры вместо общих слов («500+ объектов» вместо «много опытных объектов»); честный тон FAQ (прямые ответы про сроки/оплату/гарантию); прозрачность процесса (фотоотчёт, доступ на объект); открытая публикация сертификатов/СРО/ISO — редкость на рынке, обязательно использовать как отличие.
